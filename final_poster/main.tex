  \begin{block}{Motivation}

    A \textbf{world model} learns a representation it can roll forward to
    predict the future. DreamerV3~\citep{hafner2025dreamerv3} learns one
    \textbf{sequentially} with a recurrent state-space model (RSSM)
    \citep{hafner2019planet}: each observation becomes a stochastic latent
    joined to a deterministic recurrent state, trained to reconstruct and to
    predict its own next latent. A VAE~\citep{kingma2014vae} instead learns from
    \textbf{static} frames.

    World-model latents are increasingly reused as pretrained representations
    for control, so their content matters.

    \begin{quote}
      \textbf{What does a sequential generative latent encode beyond a static,
      per-frame model of the same observations?}
    \end{quote}

    \textbf{Probing}~\citep{alain2016probes} reads a target off a frozen
    representation; ST-DIM~\citep{anand2019atari} did this for Atari state. We
    ask a \textbf{controlled} sequential-vs-static version.

  \end{block}

  \begin{block}{Setup: a controlled comparison}

    We freeze a DreamerV3 RSSM and a static VAE and probe both. Three fairness
    controls isolate \textbf{sequential structure}:

    \begin{itemize}
      \item same encoder/decoder architecture (VAE trained from scratch);
      \item same observation model (symlog Gaussian), so likelihoods compare;
      \item same training frames (the replay buffer).
    \end{itemize}

    A probe gap then reflects sequential structure, not architecture or data.
    The VAE drops recurrence and maps one frame to a Gaussian latent via the
    (negative) ELBO:
    \[
      \mathcal{L}_\beta(x) =
      \underbrace{\mathbb{E}_{q(z\mid x)}\!\big[-\log p(x\mid z)\big]}_{\text{reconstruction}}
      + \beta\,\mathrm{KL}\!\big(q(z\mid x)\,\Vert\,\mathcal{N}(0,I)\big).
    \]

    \textbf{Task:} DMC proprioceptive Walker-Walk~\citep{tassa2018dmc}; three
    RSSM seeds ($2{\times}500$K, $1{\times}1.1$M) and one matched VAE each.

  \end{block}

  \begin{block}{Probing battery}

    Fit a probe $g$, report held-out \rtwo{} against the train mean:
    \[
      R^2 = 1 - \frac{\sum (y-g(z))^2}{\sum (y-\bar y_{\text{train}})^2}.
    \]
    Same \textbf{ridge} (primary) and \textbf{MLP} (check) everywhere; episode
    splits. We vary:

    \begin{itemize}
      \item \textbf{Targets:} current and future ($k{=}1,5,20$) state; gait phase.
      \item \textbf{Sites:} encoder; RSSM posterior ($h_t$, $z_t$); open-loop
        $k$-step prior; VAE latent.
      \item \textbf{Receptive field:} VAE with $K{=}1,4,16,\text{all}$ causal frames.
      \item \textbf{Baseline:} learned VAE-latent dynamics
        $g(z_t,a_t)\!\approx\!z_{t+1}{-}z_t$, the static analog of the prior.
    \end{itemize}

  \end{block}

  \begin{block}{Result 1: per-frame current state is shared}

    \begin{figure}
      \centering
      \includegraphics[width=0.62\linewidth]{figures/current_state_probe_r2_by_site.png}
    \end{figure}

    Encoder, RSSM posterior, RSSM deterministic state, and VAE all decode
    current state at $\rtwo\approx0.69$--$0.74$. Within the RSSM it sits mainly
    in the \textbf{deterministic state} (0.70); the stochastic latent alone is
    weaker (0.40 linear, 0.55 MLP). At equal width the continuous VAE latent
    (0.69) is the stronger \emph{linear} code.

  \end{block}

  \begin{block}{Result 2: static pooling closes the gap}

    \begin{figure}
      \centering
      \includegraphics[width=0.62\linewidth]{figures/vae_receptive_field_r2.png}
    \end{figure}

    VAE current-state \rtwo{} rises $0.69\!\rightarrow\!0.78$ with a causal
    whole-episode mean, \textbf{overtaking the RSSM posterior} (0.74). A few
    recent frames ($K{=}4,16$) are not enough. So this content is recoverable by
    hand-specified pooling, not learned recurrence.

  \end{block}

\end{column}

  \begin{alertblock}{Result 3: prediction lives in the RSSM prior}

    \begin{figure}
      \centering
      \includegraphics[width=0.66\linewidth]{figures/future_state_r2_by_horizon_posterior_vs_prior.png}
    \end{figure}

    Rolling the \textbf{prior} forward retains far more future state than a
    linear \emph{readout} of the posterior: at $k{=}20$, $\rtwo\approx0.50$ vs
    $0.16$ (about $3\times$). A learned VAE-latent dynamics model is a
    \textbf{strong baseline} (0.46). The prior still leads within every seed
    under the linear probe, but the margin shrinks ($+0.18$ at $k{=}1$ to
    $+0.05$ at $k{=}20$) toward a shared predictability ceiling.

  \end{alertblock}

  \begin{block}{Result 4: gait phase becomes linearly decodable}

    \begin{figure}
      \centering
      \includegraphics[width=0.5\linewidth]{figures/gait_phase_r2_rssm_vs_vae.png}
    \end{figure}

    Largest linear gap: gait phase decodes at $\rtwo\approx0.95$ (posterior) vs
    $0.74$ (VAE), $+0.21$. A single frame cannot place position within a cycle.
    But an \textbf{MLP} recovers most of it from the static latent (0.89 vs
    0.95): the RSSM makes cyclic structure \emph{more linearly accessible}, not
    newly present.

  \end{block}

  \begin{block}{Result 5: likelihood $\neq$ probe quality}

    \begin{figure}
      \centering
      \includegraphics[width=0.85\linewidth]{figures/generative_nll_and_reconstruction_advantage.png}
    \end{figure}

    The RSSM reconstructs with much lower NLL than the VAE (on 90--97\% of
    frames), the $1.1$M seed lower still, yet its current-state probe \rtwo{}
    barely moves. \textbf{Likelihood and linear decodability decouple.}

  \end{block}

  \begin{exampleblock}{Conclusions}

    In near-fully-observed proprioception:
    \begin{itemize}
      \item No \textbf{more current state} than a static VAE plus causal pooling.
      \item Value is \textbf{predictive} (the prior) and \textbf{coordinate-shaping}
        (it linearizes gait phase).
      \item A static representation \emph{plus dynamics} recovers most predictive
        content: recurrence is not required to access it.
      \item Generative likelihood is \textbf{not} a proxy for probe quality.
    \end{itemize}

  \end{exampleblock}

  \begin{block}{Future work}

    \begin{itemize}
      \item \textbf{Pixel / partially observed} tasks, where recurrence should
        matter more for current-state inference.
      \item More seeds and model sizes; a controlled training-length sweep.
      \item Per-component (not pooled) probing; stronger VAE-dynamics models.
      \item Does linear accessibility predict \textbf{downstream control} transfer?
    \end{itemize}

  \end{block}
